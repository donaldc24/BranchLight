Discussion About Evidence

The opening post asks how people evaluate conflicting evidence when several explanations appear plausible. It supplies context and asks participants to describe the reasoning behind their conclusions.

First perspective

One participant compares the source dates and checks whether the underlying observations can be reproduced independently.

Second perspective

Another participant looks for missing assumptions and considers whether each account explains the same set of observations.

A reply adds that uncertainty should remain visible instead of being replaced by an unjustified single answer.
